# EcovacsHomeAss (com.home.ass.app)

> 🎓 **Dự án cá nhân phục vụ mục đích học tập và nghiên cứu kỹ thuật lập trình iOS (SwiftUI, MVVM, IoT/MQTT TLS Socket).**

---

## 🌟 Tính Năng Nổi Bật

- **Zero-Server (100% Client-side):** iPhone kết nối trực tiếp đến Ecovacs Cloud, không cần máy chủ trung gian hay cấu hình mạng phức tạp.
- **Bản đồ LiDAR & Đường đi Thời gian thực (Real-time Map):** 
  - Xem vị trí robot và hướng di chuyển trực tiếp trên bản đồ phòng khi đang dọn dẹp.
  - Vẽ vệt đường đã dọn dẹp (Cleaning Trajectory) theo thời gian thực.
  - Thống kê diện tích ($m^2$) và thời gian dọn dẹp trực tiếp trên HUD.
- **Điều khiển Toàn diện:** Bắt đầu dọn, tạm dừng, về dock sạc, chỉnh lực hút, lượng nước, âm lượng, khóa trẻ em.
- **Theo dõi Linh kiện & Phụ kiện:** Xem tuổi thọ chổi chính, chổi ven, màng lọc HEPA và cảm biến, hỗ trợ reset sau khi bảo dưỡng.
- **Lưu phiên vĩnh viễn:** Đăng nhập một lần duy nhất, dữ liệu lưu trong iOS Keychain an toàn.

---

## 📲 Cài Đặt IPA Lên iPhone

File cài đặt `.ipa` được đóng gói tự động qua GitHub Actions:
1. Tải file `.ipa` từ mục **Releases**.
2. Cài đặt lên iPhone thông qua **TrollStore**, **Scarlet**, **AltStore** hoặc **Sideloadly**.
